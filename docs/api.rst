API Reference
=============

The package root intentionally exposes only ``__version__`` and the wrapper
submodules. Use ``design_research.problems``, ``design_research.agents``,
``design_research.experiments``, and ``design_research.analysis`` for the
public re-export surface of the exact component versions pinned by this
umbrella release. See :doc:`compatibility` for that tested combination; each
component owns the lifecycle of its exported symbols.
